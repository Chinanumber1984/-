# SRM 交互演示

打开 `SRM演示.html` 即可在常见现代浏览器体验，不需要后端、账号或安装依赖。文件已内联Vue运行时代码与样式，不依赖CDN。组织/角色是演示视角切换，数据只在浏览器内保存；如浏览器禁用本地文件或localStorage，可用静态HTTP服务打开，当前页仍不调用业务API。

推荐体验：

1. 新建供应商，输入虚构名称与地址，保存草稿。
2. 直接提交可看到资质门槛；切换“资质证书”，点击“补齐演示资质”，再提交准入。
3. 关闭档案，右上角切换“质量工程师”，打开该供应商、填写意见并通过。
4. 切换“采购经理”，完成准入审批；查看“审批记录”。
5. 切换华南组织，检查供应商范围；切换“供应商管理员”，检查仅本人供应商视角。
6. 左下角可重置全部演示数据，不影响真实开发数据库。

这是交互原型：不上传真实附件、不采集真实银行账号、不连接Flowable/ERP，也不把浏览器记录称为签名审计。真实权限与加密基础组件在后端独立测试，参见docs/foundation。

重建和验证：

```bash
npm --prefix snowy-admin-web run demo:build
npm --prefix snowy-admin-web run demo:test
python scripts/test-demo-browser.py
```

开发服务：在snowy-admin-web执行`npm run demo`，仅供本机测试。单文件HTML是交付给用户查看的主要入口。

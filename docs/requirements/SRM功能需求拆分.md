# SRM 系统功能需求拆分（FRD v1.0）

> 配套文档：《SRM基于Snowy重建设计方案.md》v1.1（架构/技术栈/决策已锁版）
> 用途：把方案 §5 的"实体级"粗需求拆成**可评审、可分工、可验收**的功能点级需求
> 底座：Snowy 3.x（Vue3 + AntDV + SpringBoot3 + MP + Sa-Token + 国密）
> 范围：M1 准入生命周期 / M2 寻源 / M3 采购协同 / M4 绩效与风险 / M5 供应商门户 / M6 工作流 / M7 集成

---

## 0. 拆分规则

### 0.1 层级与编号
- **L1 模块** = 插件级（如 M1 srm-core）
- **L2 子功能** = 业务域（如"资质管理"）
- **L3 功能点** = 具体可交付功能，编号 `FR-{模块缩写}-{3位}`（如 `FR-CORE-201`）
- **L4 用例/规则** = 复杂功能点展开的"操作序列 + 校验规则"，在表格内列明

### 0.2 角色表（基于 Snowy RBAC 扩展）
| 角色编码 | 角色 | 来源/范围 | 关键权限 |
|----------|------|-----------|----------|
| SYS-ADMIN | 系统管理员 | Snowy 内置 | 用户/角色/组织/字典/菜单 |
| SRC-SPE | 寻源专员 | SRM 新增 | RFQ/竞价/定点发起与查看 |
| BUYER | 采购员 | SRM 新增 | PO 协同、对账跟进 |
| CAT-MGR | 品类经理/采购经理 | SRM 新增 | 准入与定点审批、品类字典 |
| SQE | 供应商质量工程师 | SRM 新增 | 资质/PPAP/SCAR/评分质量项 |
| SUP-ADMIN | 供应商主数据管理员 | SRM 新增 | 供应商档案/资质/联系人维护 |
| FIN | 财务 | SRM 新增 | 对账/发票协同 |
| PORTAL-U | 供应商联系人 | 门户（多角色）| 仅本供应商数据；按 `roles` 限功能 |

> 多法人：所有内部角色经 Snowy **组织(org) + 数据权限范围** 隔离；门户角色经 `supplier_id` 隔离。

### 0.3 统一复用（不重复设计，仅标注约束）
下列能力直接复用 Snowy，FRD 不再逐条展开：RBAC/组织/岗位、字典、菜单/按钮、附件(MinIO)、操作/登录签名审计日志(`@CommonLog`)、国密 SM2/SM3/SM4、代码生成(gen)、消息中心、待办中心、定时任务框架。

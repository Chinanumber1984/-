## 1. 项目背景与目标

### 1.1 背景
集团采购长期依赖线下/Excel + ERP 物料与订单模块，存在供应商资质过期无人预警、寻源比价无留痕、订单交付不透明、绩效靠人工打分、风险事后才发现等问题。需要一套**私有化、可审计、与 ERP/MES/QMS 打通**的 SRM 系统，实现供应商从准入到淘汰的全生命周期线上化。

### 1.2 建设目标（可量化）
- 供应商准入周期从 ~15 天降至 ≤ 5 天（资料自助提交 + 并行审批）
- 寻源 100% 线上留痕，比价结论可追溯到明细
- 订单交付准时率（OTD）可视化，异常自动预警
- 供应商绩效自动计算覆盖率 ≥ 90%，替代手工 Excel
- 资质过期、合规风险自动预警，覆盖率 100%

### 1.3 范围
**包含（In Scope）**
- 供应商主数据与准入生命周期（注册、资质、准入、变更、冻结/淘汰）
- 寻源管理（RFQ、询比价、反向竞价、定点决策，不含招投标）
- 采购协同（采购订单、发货/收货、交付跟踪、对账、发票协同）
- 供应商绩效与风险（评分卡、分级、质量协同 SCAR/8D、风险预警、合规）
- 供应商门户（自助服务）
- 系统管理（组织、角色、权限、主数据、审计）

**不包含（Out of Scope）**
- 正式招投标/电子招投标（依法必须招标项目走单独招采平台）
- ERP 内部的 MM/财务记账（SRM 只做协同与推送）
- MES/QMS 自有业务（SRM 通过接口消费其结果）

### 1.4 关键假设
- 集团多组织（多个法人/工厂），数据按组织隔离 + 集团视图
- 供应商数量级：活跃 ~3000，潜性 ~8000
- 信创环境可选：操作系统麒麟 V10 / 统信 UOS；数据库达梦 DM / 人大金仓 Kingbase；中间件东方通 TongWeb
- 消息通道：企业微信 / 钉钉 / 邮件（至少支持一种）

## 3. 角色与权限（RBAC）

| 角色编码 | 角色名称 | 主要职责 |
|----------|----------|----------|
| PUR-BUYER | 采购员 | 发起寻源、维护订单、对账 |
| PUR-MGR | 采购经理 | 审批定点、审批准入、查看绩效 |
| SQM | 供应商质量工程师(SQE) | 资质审核、PPAP、SCAR 闭环 |
| FIN | 财务对账岗 | 对账、发票协同、付款推送 |
| SUP-ADMIN | 供应商管理员(采购侧) | 主数据、分级规则配置 |
| SUP-USER | 供应商用户 | 门户自助（资料、应答、发货、对账）|
| AUDIT | 审计/合规 | 只读 + 全量审计查看 |
| SYS-ADMIN | 系统管理员 | 组织、角色、权限、参数 |

权限模型：组织维度隔离（数据权限）+ 功能维度（菜单/操作权限）+ 字段级敏感权限（如单价对 SQM 隐藏）。

## 4. M1 供应商准入与生命周期管理

### 4.1 功能描述
管理供应商从**潜在→准入→合格→冻结/淘汰**的全生命周期，覆盖主数据、资质证书、准入审批、信息变更。

### 4.2 主要用例
| 用例 | 名称 | 角色 | 说明 |
|------|------|------|------|
| UC-M1-01 | 供应商自助注册 | SUP-USER | 门户提交基础信息 + 资质，生成潜在供应商 |
| UC-M1-02 | 资质审核 | SQM/PUR-MGR | 体系证书、营业执照、行业许可审核 |
| UC-M1-03 | 准入审批 | PUR-MGR | 多节点并行/串行审批，生成合格供应商 |
| UC-M1-04 | 信息变更 | SUP-USER/SUP-ADMIN | 银行、联系人、产能变更，需重审 |
| UC-M1-05 | 冻结/解冻 | SUP-ADMIN | 风险/绩效触发 |
| UC-M1-06 | 淘汰退出 | PUR-MGR | 留痕，关联交易冻结 |

### 4.3 关键实体与字段（供应商主数据 Supplier）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| supplier_code | String | 是 | 供应商编码（MDM 生成，全局唯一）|
| supplier_name | String | 是 | 名称（含中/英文）|
| legal_entity | String | 是 | 所属法人/工厂（组织维度）|
| category | Enum | 是 | 物料类别（原料/辅料/设备/服务…）|
| tier | Enum | 是 | 战略/优选/合格/限定/潜在 |
| status | Enum | 是 | 潜在/审核中/合格/冻结/淘汰 |
| credit_code | String | 是 | 统一社会信用代码 |
| bank_account | String | 是 | 银行账号（敏感字段）|
| contact | JSON | 是 | 联系人/电话/邮箱 |
| cert_list | JSON | 否 | 资质证书列表（见 4.4）|

### 4.4 资质证书（Certificate）
| 字段 | 说明 |
|------|------|
| cert_type | 营业执照/ISO9001/IATF16949/环保/行业许可 |
| cert_no | 证书编号 |
| valid_from / valid_to | 有效期 |
| attachment | 附件 |
| **系统规则** | 到期前 30/15/7 天分级预警；过期自动置供应商"受限" |

### 4.5 状态机
```
潜在 ──注册──▶ 审核中 ──审核通过──▶ 合格
   │              │                  │
   │          审核驳回              冻结(风险/绩效)
   ▼              ▼                  │
 淘汰◀────────── 淘汰 ◀────────────┘
               合格 ──淘汰审批──▶ 淘汰（交易冻结）
```

## 5. M2 寻源管理（不含招投标）

### 5.1 功能描述
覆盖 **RFQ 发放 → 供应商应答 → 询比价/反向竞价 → 定点决策 → 生成采购价格/框架协议** 的闭环。不含依法招标。

### 5.2 主要用例
| 用例 | 名称 | 角色 | 说明 |
|------|------|------|------|
| UC-M2-01 | 创建 RFQ | PUR-BUYER | 选品类/物料、邀标供应商、发门槛 |
| UC-M2-02 | 供应商应答 | SUP-USER | 门户填单价/交期/容量，附件报价单 |
| UC-M2-03 | 询比价分析 | PUR-BUYER | 系统自动汇总横向比价表 |
| UC-M2-04 | 反向竞价 | PUR-BUYER | 多轮实时降价，价格曲线留痕 |
| UC-M2-05 | 定点决策 | PUR-MGR | 关联历史绩效/风险，审批定点 |
| UC-M2-06 | 生成价格/协议 | PUR-BUYER | 推送 ERP 维护采购信息记录 |

### 5.3 关键字段（RFQ / Quotation）
| 实体 | 字段 | 说明 |
|------|------|------|
| RFQ | rfq_no, title, material_list, invite_suppliers, deadline, strategy(比价/竞价) | |
| Quotation | unit_price, moq, lead_time, valid_days, total_amount, attachment | 单价对 SQM 隐藏 |
| Award | awarded_supplier, award_qty, reason, risk_ref | 定点结论可追溯 |

### 5.4 业务规则
- 比价表自动计算：单价、含税价、运费、综合到厂价（含权重公式可配置）
- 反向竞价：起始价→最低价实时刷新，结束前 5 分钟出价自动延时（防狙击）
- 定点须关联近 12 个月绩效等级；绩差供应商定点需加签说明
- 所有寻源结论写入**不可篡改审计日志**

## 6. M3 采购协同

### 6.1 功能描述
与 ERP 打通，管理 **采购订单确认 → 发货/收货 → 交付跟踪 → 对账 → 发票协同**。

### 6.2 主要用例
| 用例 | 名称 | 角色 | 说明 |
|------|------|------|------|
| UC-M3-01 | 订单同步/确认 | SUP-USER | ERP 推送 PO，供应商门户确认/异议 |
| UC-M3-02 | 发货通知(ASN) | SUP-USER | 填发货明细、批次、序列号(如需) |
| UC-M3-03 | 收货/来料检验 | SQM/MES | 接收 QMS 检验结果 |
| UC-M3-04 | 交付跟踪 | PUR-BUYER | OTD、延期预警看板 |
| UC-M3-05 | 对账 | FIN/SUP-USER | 按 PO+收货自动生成对账单 |
| UC-M3-06 | 发票协同 | FIN | 发票登记/匹配/推送财务共享 |

### 6.3 关键字段
| 实体 | 字段 |
|------|------|
| PO | po_no, material, qty, price, due_date, confirmed(Y/N) |
| ASN | asn_no, po_no, delivery_lines, batch_no, serial_no, etd/eta |
| Reconciliation | rec_no, po_list, received_qty, amount, diff, status |
| Invoice | invoice_no, amount, matched(Y/N), push_status |

### 6.4 业务规则
- 收货量 > 订单量容差（如 +3%）自动标记差异，需采购确认
- 未确认 PO 不得发货；逾期 PO 自动进入预警
- 对账差异 > 阈值自动挂起，转人工

## 7. M4 供应商绩效与风险（含质量协同）

### 7.1 功能描述
自动采集交付、质量、成本、服务数据，按**评分卡**计算绩效并分级；同时做**风险与合规**监控（资质、财务、舆情、履约）。

### 7.2 绩效评分卡（Scorecard）
| 维度 | 指标 | 权重(默认可配) | 数据源 |
|------|------|----------------|--------|
| 交付(Q) | OTD 准时率、交期达成 | 30% | M3 / ERP |
| 质量(Q) | 来料合格率、PPAP 通过、SCAR 关闭率 | 35% | QMS |
| 成本(C) | 价格竞争力、降价达成 | 20% | M2 / ERP |
| 服务(S) | 响应速度、配合度 | 15% | 人工评 |

综合分 → 等级：A 战略 / B 优选 / C 合格 / D 受限 / E 淘汰候选。

### 7.3 质量协同
- **PPAP**：供应商提交样件/过程文件，SQE 审批，留档
- **SCAR/8D**：来料异常触发 SCAR，供应商 8D 回复，SQE 验证关闭
- 来料不合格率超阈值自动扣分 + 触发风险事件

### 7.4 风险与合规
| 风险类型 | 触发 | 动作 |
|----------|------|------|
| 资质过期 | 证书到期 | 预警 + 受限 |
| 财务/舆情 | 外部接口/人工录入 | 预警 + 冻结建议 |
| 履约异常 | 连续延期/重大质量 | 降级 + 触发 M1 冻结 |
| 合规 | 黑名单/制裁名单 | 硬阻断交易 |

### 7.5 主要用例
| 用例 | 角色 |
|------|------|
| UC-M4-01 绩效自动计算(月度/季) | SYS/定时 |
| UC-M4-02 评分卡查看与申诉 | SUP-USER/PUR-MGR |
| UC-M4-03 SCAR 发起与闭环 | SQM/SUP-USER |
| UC-M4-04 风险事件处理 | SUP-ADMIN/PUR-MGR |

## 9. 集成需求

| 系统 | 方向 | 内容 | 方式 |
|------|------|------|------|
| ERP(用友/金蝶/SAP) | 双向 | 供应商主数据、PO、价格、收货、付款 | REST/IDoc/ESB |
| MES | 入 | 生产领用/排产（交付优先）| API |
| QMS | 双向 | 来料检验、PPAP、SCAR | API |
| 财务共享 | 出 | 对账、发票、付款申请 | API |
| OA | 双向 | 审批流（准入/定点/冻结）| 待办回调 |
| MDM | 入 | 主数据编码、组织 | API |
| 消息(企微/钉钉/邮件) | 出 | 预警、待办 | Webhook |

集成规范：统一 API Gateway + Token 鉴权；异步走消息队列；失败重试 + 对账补偿；接口 SLA 99.5%。

## 10. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 列表查询 ≤ 2s（万级数据）；竞价实时推送 ≤ 1s；并发 ≥ 500 用户 |
| 安全 | 等保三级；传输 TLS1.2+；密码加盐哈希；敏感字段加密(银行账号/单价) |
| 审计 | 全量操作留痕，不可篡改，保留 ≥ 5 年 |
| 可用性 | 年可用 ≥ 99.9%；RPO ≤ 15min，RTO ≤ 2h |
| 信创 | 支持麒麟/统信 + 达梦/金仓；ARM 适配可选 |
| 多组织 | 数据按法人/工厂隔离 + 集团汇总视图 |
| 可维护 | 参数化(评分权重、预警阈值、审批流)可配置，少改码 |

## 11. 验收标准（要点）
- 四大模块端到端跑通，与 ERP 主数据/PO 双向同步正确
- 供应商准入全流程线上化，资质到期预警 100% 触发
- 寻源比价/竞价结论可追溯到明细与审批
- 绩效月度自动计算，与 QMS/ERP 数据一致（偏差 ≤ 1%）
- 等保三级测评通过；敏感字段加密；审计不可篡改

## 12. 实施路线（建议）
1. **一期**：主数据 + 准入生命周期 + 供应商门户 + 等保基座
2. **二期**：寻源（比价/竞价）+ 采购协同（PO/ASN/对账）
3. **三期**：绩效评分卡 + 质量协同 + 风险预警 + BI 看板

## 推荐查看顺序

1. 打开 Demo，使用“新建供应商”，保存后查看资质页、补齐演示资质并提交准入。
2. 右上角切换“质量工程师”，处理SQE任务；再切换“采购经理”，准入审批通过。
3. 切换组织检查两套演示供应商，切换“供应商管理员”检查仅显示一家。
4. 阅读本目录的决策、数据、权限和API，确认下一阶段实现依据。

## 不应混淆的三个结果

- 演示：浏览器模拟，可体验交互；角色切换不是身份认证，localStorage不是业务存储或安全边界。
- 工程基础：真实Java策略/加密实现、MySQL迁移、自动化测试；这些内核尚不代表门户与审批业务API已上线。
- 外部确认：业务规则签字、生产密钥管理、接口沙箱、信创/等保测评，未由本次操作伪造完成。

部署到生产前必须由可信会话适配器调用权限策略，并在所有服务/SQL/导出/附件/任务/WS入口统一约束；当前 Demo 不可作为正式供应商门户发布。

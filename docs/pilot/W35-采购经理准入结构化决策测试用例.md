# W35 采购经理准入结构化决策测试用例

## 范围

补齐 PRD FR-CORE-403 的采购经理决策记录：经理处理准入申请时，必须分别选择品类必要性和绩效结论；决策与审批意见一起加密留档。仅使用隔离副本和合成供应商，不在主实例创建或审批申请。

## 前置条件

1. 从主实例一致性备份恢复到隔离副本，确认隔离副本使用独立数据库、密钥和端口。
2. 使用已有内部账号权限映射或临时测试身份，准备一份资质完整的合成潜在供应商。
3. SQE 完成准入节点后，由具备 CAT-MGR 权限的账号打开同一申请的经理节点。

## 用例

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| W35-01 | 打开准入经理节点并选择“同意” | 表单显示申请品类、近12个月有效绩效/平均分/缺失月份，以及必填的“品类必要性”“绩效评估结论”和审批意见；不选择前两项不能提交。 |
| W35-02 | 选择“必要 / 通过”，填写意见并同意 | 审批成功；申请历史意见中可读到结构化结论和审批意见；档案按既有 Flowable 规则回写合格。 |
| W35-03 | 选择“非必要 / 有条件通过”，填写依据并同意 | 审批成功；历史保留“非必要 / 有条件通过”与理由。 |
| W35-04 | 选择“必要 / 不通过”并尝试同意 | 服务端拒绝，流程任务仍待处理，档案状态不变。 |
| W35-05 | 选择“非必要 / 不通过”并执行驳回 | 驳回成功；历史记录包含结构化结论和理由，档案按既有驳回规则回写。 |
| W35-06 | 选择“通过”并执行驳回 | 服务端拒绝，流程任务仍待处理，档案状态不变。 |
| W35-07 | 直接调用审批接口，缺少枚举字段或提交非法枚举 | 服务端以参数校验错误拒绝，不推进流程，不写入审批动作。 |
| W35-08 | 处理冻结、变更、解冻等非准入审批 | 不显示准入专用字段；现有审批动作正常工作。 |
| W35-09 | 使用门户账号或无组织/审批角色权限账号读取、提交 | 按既有服务端授权规则拒绝；不得通过请求参数指定审批人身份或作用范围。 |

## 记录

逐项记录执行账号、隔离副本构建版本、审批编号、结果和脱敏截图。不要导出或记录密钥、完整信用代码、银行账号或真实供应商附件。

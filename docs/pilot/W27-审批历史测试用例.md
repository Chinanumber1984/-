# W27 已办与审批历史测试用例

阶段目标：为内部审批工作台增加已结束流程列表、状态/业务类型筛选、分页和节点时间线。列表只显示用户本人发起、本人经办的审批；流程管理员仅在其既有组织/数据权限范围内查看。详情沿用原审批详情的字段授权。门户无权访问内部审批历史。

## 执行说明

- 在本地入口 `http://localhost:18080/` 选择内部工作台登录。
- 使用 `admin` 检查流程管理员范围；使用 `lijunhua` 检查普通经办人范围。账号凭证从本机私有账号文件读取，不写入本用例。
- 进入“审批工作台”，在“待我处理 / 已办 / 审批历史”间切换。全部步骤只读，不审批、撤回或修改流程。
- 若当前账号没有已结束流程，记录空状态，不创建新审批充数。要验证时间线，可选择已有申请人本人发起或已有本人工单记录的流程。

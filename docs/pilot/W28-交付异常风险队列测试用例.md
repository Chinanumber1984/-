# W28 交付异常风险队列测试用例

入口：`http://localhost:18080/`，内部用户 lijunhua 或 admin 登录，进入“质量与风险”→“内部风险”。仅查看/筛选已存在记录；本用例不创建订单、收货、风险或审批，不修改数据库。

## 手工验收

| 编号 | 级别 | 步骤 | 预期结果 | 结果 |
|---|---|---|---|---|
| W28-01 | P1 | 打开内部风险列表，选择“风险类型=履约异常” | 只显示采购履约触发的 DELIVERY_EXCEPTION 记录，供应商、状态、等级和来源分类可见 | 待整体验收 |
| W28-02 | P1 | 选择“待评估”并查看任一履约异常详情 | 详情显示逾期/容差类型及可追查单据依据；不得出现订单单价或密钥 | 待整体验收 |
| W28-03 | P1 | 依次筛选高、中、低等级；再切换“已评估/预警跟进中/已归档” | 每次筛选从第1页开始，所有行符合所选筛选项；空结果有明确提示 | 待整体验收 |
| W28-04 | P1 | 同时选择风险类型、状态和等级 | 结果满足全部筛选条件，分页总数与当前过滤范围一致 | 待整体验收 |
| W28-05 | P1 | 不指定筛选条件并翻页 | 仍按当前数据范围列出风险；每页最多20条，不丢失筛选状态 | 待整体验收 |
| W28-06 | P1 | 供应商门户账号 lixiaolong / gysadmin 尝试直接打开内部风险接口 | 返回403，门户不显示内部风险评估队列 | 待整体验收 |
| W28-07 | P1 | 对高风险行使用“查看风险” | 冻结建议与审批状态可见；仅既有经理审批可以改变供应商状态 | 待整体验收 |

当前自动化验收只读取列表并验证过滤、分页参数、角色拒绝和来源字段；不替代上述业务人员验收，也不更改“待业务逐项验收”状态。

# W29 品类字典与寻源范围测试用例

入口：`http://localhost:18080/`，内部 `admin` 或具有 CAT-MGR 权限的账号登录。自动化写入只在保留卷的隔离副本中执行。主实例手工验收如需新建测试品类，请使用 `W29_TEST_` 前缀，完成后停用品类并确认没有真实供应商或询价使用它。

## 手工验收

| 编号 | 级别 | 步骤 | 预期结果 | 结果 |
|---|---|---|---|---|
| W29-01 | P1 | 打开“品类字典”，查看已有条目 | 显示编码、名称、准入所需资质和启用状态；供应商/寻源用户可见的品类一致 | 待整体验收 |
| W29-02 | P1 | 新建唯一编码的测试品类，勾选营业执照与 ISO9001 | 保存后列表可见；门户公开注册品类仅包含启用品类 | 待整体验收 |
| W29-03 | P1 | 修改测试品类名称和必需资质 | 保存后版本更新；准入校验使用更新后的必需资质 | 待整体验收 |
| W29-04 | P1 | 停用测试品类后打开“寻源与竞价”新建询价 | 停用品类不出现在询价品类选择项中 | 待整体验收 |
| W29-05 | P1 | 通过候选供应商查询尝试请求停用品类 | 服务端返回品类已停用错误，不返回该品类供应商 | 待整体验收 |
| W29-06 | P1 | 对停用品类提交询价草稿，再恢复启用后重试 | 停用期间创建被拒；启用后仅同品类且当前组织的合格供应商可被邀请 | 待整体验收 |
| W29-07 | P1 | 使用普通供应商门户账号读取品类列表并尝试维护品类 | 门户列表不返回停用品类；维护接口返回403 | 待整体验收 |
| W29-08 | P1 | 用旧版本号更新测试品类 | 返回409并要求刷新；其他已存在品类和供应商档案不变 | 待整体验收 |

自动化用例创建独立 `W29_VERIFY_*` 品类，验证新增/修改/停用/恢复、失效类别的候选列表阻断、组织和供应商类别约束及门户拒绝。记录会保留在隔离副本供复核，不会修改主实例类别、供应商、询价或数据库卷。

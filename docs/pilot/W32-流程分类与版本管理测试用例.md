# W32 流程分类与版本管理测试用例

## 范围

验证流程管理界面可识别并维护当前系统支持的 SRM 业务流程分类，上传流程版本保留分类映射和受控 BPMN 规则。测试使用隔离副本，不在主实例发布新流程版本或挂起在用定义。

## 前置条件

- 使用隔离副本和流程管理员账号；准备可回滚的测试 BPMN 文件。
- 隔离副本已部署准入、关键资料变更、冻结、解冻、淘汰、定点、采购协同审核、质量审核流程。
- 记录各流程定义 ID、分类、流程键、版本及挂起状态。

## 用例

1. **分类展示完整**：打开审批中心的“流程版本与分类”，确认分类包括准入申请、关键资料变更、冻结申请、解冻申请、淘汰申请、寻源定点、采购协同审核及质量审核。
2. **定义列表映射**：检查现有流程行均显示可读的分类、流程键、版本和状态；空/未知分类显示“未分类”且不误标为其他业务。
3. **上传分类可选**：选择每一项分类时，上传表单与列表使用相同分类名；对一个测试流程上传合规 BPMN 后，检查新版本分类字段与流程键一致。
4. **流程安全校验保留**：尝试上传带脚本、服务任务、未知节点或错误候选角色的 BPMN，确认被拒绝且当前激活版本不变。
5. **版本切换与存量流程**：在隔离副本发布该类型新版本，确认新申请使用新版本、已有待办仍可按原流程处理；挂起/恢复只影响新申请。
6. **权限边界**：普通内部账号与供应商门户账号均不能发布、上传或挂起流程定义。

## 验收记录

记录测试账号、流程定义 ID、版本、分类、错误上传结果和操作前后挂起状态。此用例覆盖系统内流程管理，不替代业务负责人签收。

## 执行约定

- Windows 浏览器使用主实例：内部入口 `http://localhost:18080/?internal=1`；供应商入口 `http://localhost:18080/?portal=1`。本轮隔离入口 `18081` 只用于说明自动模拟，不作为你的验收入口。
- 账号使用 `lijunhua`（内部经办）、`admin`（管理员/SQE及经理审批）、`lixiaolong`（供应商测试员）、`gysadmin`（门户管理员）。密码沿用你已设置的统一测试密码；不要把密码写入截图、缺陷或本表。
- 建议普通窗口登录内部，隐私窗口登录门户；切换账号先退出。验证码按当前设置正常输入。
- 每次只用新建且带本轮标识的记录，例如 `验收-20261104-01`。不要对已有真实供应商发起报价、审批、冻结、淘汰或付款操作；不要清库、删记录、覆盖正式资质。
- 用户门户账号绑定同一家受邀供应商。因此，验证跨供应商隔离时只记录“当前账号无法看到其他供方”，不要把两个门户账号误当作两个供应商。
- 用例状态填写：通过、失败、阻塞、不适用。失败需记录单号、账号角色、实际/预期差异和截图；不要截取密码、密钥、完整银行账号或证件号码。
- 采购协同的 ERP、MES、财务按钮如标注“沙箱/模拟”，只验证本地演示链路，不代表外部系统已联调，也不代表已付款。

# W34 流程图形设计测试用例

范围：系统管理员在流程版本页对已发布流程调整图形布局或节点名称，并安全发布为新版本。此编辑器基于受控 SRM 模板，审批节点类型、候选角色及业务顺序不能变更。

## 用例

| 编号 | 账号/前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| W34-01 | `admin` 登录，进入设置中的流程版本管理 | 打开一个已发布流程的“图形设计” | 画布显示 BPMN 节点、连线和当前布局；打开失败时显示错误，不能保存 |
| W34-02 | 流程图已打开 | 拖动节点、更改节点名称，点击“校验并发布新版本” | 发布成功；版本号增加，列表显示新版本；流程分类、候选角色和业务顺序保持受控值 |
| W34-03 | 新版本已发布 | 下载新版本 BPMN 并再次打开图形设计 | 新布局和名称仍可见，流程图可再次编辑 |
| W34-04 | 新旧版本均存在 | 挂起旧版本，检查一个已存在的旧流程实例并新发起一条申请 | 挂起版本不再接受新申请；已有实例仍可按原流程继续办理 |
| W34-05 | 准备一份含服务任务、脚本、错误候选角色或外部实体的 BPMN | 通过文件上传发布 | 服务端拒绝并返回受控模板校验错误；当前可用流程版本不改变 |
| W34-06 | 以非流程管理员登录 | 查看流程版本管理与尝试调用发布/上传接口 | 页面不显示管理入口，服务端拒绝未授权写入 |

## 验收记录

- 自动校验：`SrmBpmnValidatorTest` 覆盖受控 BPMN 图形数据可通过、服务任务被拒绝、伪造 BPMN DI 命名空间被拒绝。
- 前端构建、Flowable 模块测试及本地部署冒烟结果写入 `docs/review/W34-verification.json`。
- 手工账号验收由整体验收阶段执行；本工作包不在主运行库发布或挂起真实流程。

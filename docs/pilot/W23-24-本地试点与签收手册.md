## 建议验收顺序

1. **准备记录**：打开 [114项签收矩阵](P8-114-acceptance-matrix.csv)，按编号记录测试人、日期、实际结果、缺陷号、截图/证据路径和业务签收人。先确认编号状态是“待业务逐项验收”；不要把自动化报告直接填成业务通过。
2. **账号和权限**：四个账号分别登录；内部用户打开组织/供应商及寻源工作台，两个门户账号确认绑定企业和收到的RFQ。检查门户身份无法访问内部路由，且看不到系统设置。使用不同账号的无痕窗口避免会话互相替换。
3. **供应商准入**：按 [W12–15手工验收用例](../review/manual-acceptance/W12-15-手工验收用例.xlsx) 新建明显标注“业务验收”的供应商和资质附件，提交申请；由不同审批人完成两级审批。核对附件、审批历史、重复提交、补正和状态，不修改原有真实供应商资料。
4. **寻源和报价**：创建新的、截止时间充足的RFQ，只邀请本测试供应商；发布后用 `lixiaolong` 报价，再以内部用户核对匿名报价、比价和审批记录。按同目录的手工用例记录每项结果。不要对已有业务RFQ提交测试报价。
5. **采购协同**：按 [W16–19采购协同验收用例](../review/manual-acceptance/W16-19-采购协同验收用例.xlsx) 使用带验收标识的新PO/ASN/收货/对账/发票数据。每步核对幂等键、版本和金额；不要把真实ERP或财务凭证写入本地沙箱。
6. **质量和风险**：按 [W20–22质量风险验收用例](../review/manual-acceptance/W20-22-质量风险验收用例.xlsx) 提交新PPAP/8D及附件、完成SQE退回/重提/批准和有效性闭环。冻结/解冻、扣分及重复缺陷只用隔离测试供应商；不对现有供应商更改等级或生命周期。
7. **外部系统**：ERP、MES、QMS、财务系统的真实端到端联调须在对应方提供测试环境、接口字典、回调配置和测试凭证后另行执行。本机集成沙箱/HMAC证据不可记作真实联调通过。
8. **签收与缺陷**：114项每一行都要对照PRD全部特异AC及G1–G6完成正向、异常和权限验证。缺陷记录责任人、严重级别、复现步骤、版本和复测结果。未测、部分实现、外部受阻或只有自动化证据的行保持未签收。

## 本阶段自动验证和限制

P8隔离副本 `http://localhost:18081/` 从备份恢复，仅用于本阶段自动化检查，包含恢复快照和10,000条合成潜在供应商压测记录。验证后已停止副本容器，数据库卷、附件卷、备份和合成数据均保留；业务人员使用仍在运行的18080主入口。P8副本的浏览器/API、备份恢复、迁移校验和故障演练报告位于 `docs/review/P8-*-verification.json`。

如需重看隔离副本，在项目根目录执行以下启动命令；18081仅供恢复副本检查：

```bash
docker compose \
  --project-directory .runtime/pilot/recovery-20261028/bundle \
  --env-file .runtime/pilot/recovery-20261028/bundle/runtime/compose.env \
  -f .runtime/pilot/recovery-20261028/bundle/compose.drill.json \
  -p srm-drill-p8-20261028 up -d --wait
```

本地10k供应商列表测得P95为298毫秒（100次测量、8并发、15次预热）。它不代表生产集群容量。月度全量评分≤2小时、50家真实受邀方端到端广播、真实ERP/MES/QMS/财务联调、最新两代Windows浏览器兼容性矩阵、生产RPO/RTO、五年审计保留、KMS/等保/信创/PostgreSQL适配均未由本阶段验证。

当前 `docs/backlog.csv` 有84项标记为已实现、30项部分实现。114项业务签收均待逐项填写；不能仅凭构建、演示或自动化用例宣布全功能验收完成。参见 [P8验收状态与范围](README.md)。

## 备份与恢复

已生成私有备份 `.runtime/pilot/backup-20261028/`，包含数据库、应用包、密钥配置快照和文件卷；它不进入Git。校验：

```bash
python3 scripts/review-recovery.py verify .runtime/pilot/backup-20261028
```

恢复必须使用新的目录、`srm-drill-*` 项目名及非18080端口；脚本拒绝覆盖已存在目录、项目或数据卷：

```bash
python3 scripts/review-recovery.py restore \
  .runtime/pilot/backup-20261028 \
  --dest .runtime/pilot/recovery-next \
  --project srm-drill-p8-next \
  --port 18082
```

恢复副本的应用/数据库服务在内部Docker网络，只有浏览器网关另接入已发布端口的入口网络。不得把该副本当成供应商联调环境，也不要将副本账号或密钥发布到Git/聊天。

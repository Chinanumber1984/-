# W26 供应商门户工作台测试用例

阶段目标：供应商登录后进入工作台，集中查看本方询价/竞价、待确认对账、SCAR整改、资质提醒和绩效概览，再跳转到原业务页面操作。工作台只读，不新建业务记录。外部系统接口不在本阶段范围内。

## 执行说明

- 本机试点入口：`http://localhost:18080/`；选择“供应商门户”登录。
- 用 `gysadmin` 检查门户管理员路径，用 `lixiaolong` 检查供应商测试员角色差异。密码从本机私有账号文件读取，不记录在测试文档或截图中。
- 先看工作台及对应模块是否有数据。若当前绑定供应商没有该类数据，验证空状态和导航即可；不要为通过测试而改动主库数据。
- 资质、寻源、协同、质量与绩效列表应仅显示当前登录联系人绑定供应商的数据。测试人员不可通过工作台切换供应商。
- 所有步骤均为读取和页面导航；不点击提交、确认、上传、审批、报价、竞价或对账操作。

## 本阶段自动回归

- API脚本：`scripts/test-portal-dashboard-api.mjs`，仅在隔离副本执行登录及GET请求，校验RFQ邀请、对账详情、SCAR、绩效及资质提醒的供应商范围，不写入业务行。
- 浏览器脚本：`scripts/test-portal-dashboard-browser.py`，仅在隔离副本验证门户落地页、四类卡片跳转、无价格字段和联系人角色对应的入口启用状态。
- 机器结果：`docs/review/W26-portal-dashboard-api-verification.json`、`docs/review/W26-portal-dashboard-browser-verification.json`。

业务验收请在实际主入口用例执行后记录结果、缺陷号、测试人和业务签收人；自动回归不替代整体114项验收。

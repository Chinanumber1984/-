# 供应商门户验证码开关

访问 http://localhost:18080/?internal=1 ，以内部管理员 admin 登录，进入一级菜单“设置”→二级菜单“门户登录设置”。切换“供应商门户图片验证码”并保存。调整后刷新 http://localhost:18080/?portal=1 生效。

验证码状态以设置页的已保存值为准。关闭后无需填写图片验证码，账号和密码仍由服务端校验；开启时恢复验证码输入与服务端必填校验。内部工作台验证码配置不受影响。

开关使用现有系统配置接口，只有内部超级管理员可保存；普通测试人员和供应商门户管理员无权修改全局登录设置。不存在匿名用户自行跳过服务端校验的开关。

实际浏览器验证了关闭后无验证码字段登录成功、开启后填写真实验证码登录成功；接口回归验证了开启时不传验证码会被拒绝、越权配置被拒绝。账号密码、既有密钥和业务数据库卷保留。证据见 portal-login-settings-browser.json 与 portal-login-settings-api.json。

直达入口：http://localhost:18080/?internal=1&view=portal-login-settings 。需使用内部admin账号；主页顶部有“设置”快捷入口，侧栏在较矮屏幕支持滚动。

# SRM 本地验收包

这个包在你的电脑运行真实后端、数据库和审批流程，不依赖云环境网页预览。需要先安装并启动 Docker Desktop（Windows使用Linux容器），建议给Docker至少4GB内存、预留6GB磁盘。首次启动需要联网下载官方镜像；无需另装Java、Node或数据库。

## 开始

1. 将ZIP完整解压到一个文件夹，不要直接在压缩包里运行。
2. Windows双击 `start.cmd`；macOS/Linux在该文件夹执行 `bash start.sh`。
3. 等启动窗口显示Ready。Windows随后自动打开浏览器；其他系统在本机浏览器输入 `http://localhost:18080`。
4. 打开 `runtime/登录账号.txt`，使用发起人账号登录“内部工作台”。审批时退出并切换独立SQE、采购经理账号。

账号和加密密钥均在首次启动时在你的电脑随机生成，包里不包含云环境密码、密钥、业务数据或用户数据库备份。再次启动保留已有账号和数据，不重置密码。默认只允许本机访问，数据库和后端不向电脑网络发布端口。

## 验收顺序

发起人新建供应商 → 建立管理员联系人 → 上传品类所需有效资质 → 准入与审批中提交 → SQE登录核对资质并通过/退回补正 → 采购经理登录审批 → 发起人刷新确认合格。五类流程已由启动脚本准备。也可继续验证银行资料变更、冻结、解冻和淘汰。

附件使用本机Docker私有文件卷真实保存，下载仍需要登录与供应商权限；本地便携版不启动MinIO，云开发环境的MinIO配置不受影响。外部企微/钉钉Webhook未配置。这里只作开发验收，不作为生产部署。

## 停止与排错

Windows双击 `stop.cmd`；macOS/Linux执行 `bash stop.sh`。停止保留数据。不要执行带 `-v` 的清库命令，也不要删除runtime文件夹，否则原有加密数据可能无法读取。

启动失败时保留窗口中的错误发给开发者，不要发送runtime中的密码或密钥。若提示18080端口被占用，先关闭占用该端口的应用再重启。网页未显示Ready时不要提前进行验收。

本包在Linux Docker容器中实际启动并用Chromium验证；未在Windows/macOS宿主机执行启动脚本，Docker Desktop安装与镜像下载仍取决于你的电脑环境。

# snowy-plugin-flow

真实Flowable7引擎适配，通过flow-api向SRM业务提供实例、任务、版本与受控BPMN上传。manager任务完成时同步TaskListener发布业务回写事件；异常不被吞掉，由同一Spring数据库事务回滚引擎和业务。

模板候选组不替代业务服务的组织、数据范围、角色、申请人分离与任务归属校验。上传仅允许对应生命周期图、指定角色与受控完成监听器，拒绝DTD、脚本、任意表达式和外部服务任务。

已有实例使用启动时版本，挂起只阻止新发起。加签作为受父任务约束的独立子任务，未完成时父任务不能通过；业务历史同时保存在加密意见及签名事件中。

静态W1–2模板保留于bpmn-templates，实际W7–9流程通过管理员显式发布，不自动覆盖线上定义。交付边界见docs/lifecycle。
